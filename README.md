## CN2 GIA 和普通线路、CN2 GT 差在哪

CN2 GIA 是中国电信 CN2 骨干网（AS4809）里的最高等级服务，全称 Global Internet Access。它和普通 163 线路（AS4134）、CN2 GT 的关键区别在于去程和回程都走独立优化通道，不和公共互联网流量抢带宽。

换成体感上的差别：

- 普通 163 线路：晚高峰延迟 300ms 以上，丢包可能超过 10%，页面图片加载到一半卡住
- CN2 GT：比 163 好，但回程不一定走优化路由，高峰期会抖
- CN2 GIA：晚高峰延迟稳在 150–160ms 左右，丢包接近 0

公开测评给出的洛杉矶 CN2 GIA 数据是：中国大陆主要城市往返 150–180ms，电信线路平均可低至 162ms，三网基本 0 丢包。DMIT 洛杉矶 Pro 系列的公开测试 IP 是 154.17.2.2，下单前可以自己 ping 一轮再决定。

## 下单前必须知道的限制

**IP 被墙可以免费换。** Pro 和 EB 系列支持免费换 IP，条件是 IP 被墙，每 15 天可申请一次，联系客服操作。其他情况换 IP 收 $5。建站场景下这个保障很实际，不至于因为一次被封就整台换掉。

**25 端口默认封禁。** 想自建邮件服务器要另想办法。

**热门套餐缺货是常态。** Pro.TINY 和 Pro.Pocket 缺货不是偶发，官网会实时显示库存状态。有案例是库存页面显示有货，半小时后下单提示 Out of Stock，看到有货不要拖。

**工单响应偏慢。** 非紧急问题回复可能要等 24 到 72 小时。建站期间对实时支持依赖高的，心里要有准备。

**硬件升级不加价。** 官方会不定期升级物理机硬件，已购套餐同步升级，不额外收费。

## 退款：3 天全额有条件，条款里还有一份不退款清单

官方文档写的是 3 天内全额退款、30 天内按剩余价值部分退款，且无需理由。全额退款的具体条件是：购买不超过 3 天，且这台机器用掉的流量不超过 30GB。

几个容易忽略的细节：

- 退款可以选退回账户余额或原支付方式。退到余额不收手续费；退到原支付方式会扣支付网关收的费用，**支付宝因为退款时返还手续费，实际不收费**
- 退款请求通常在 48 小时内处理，高峰期会延迟
- 发起退款后实例会被关闭，确认退款后数据删除且无法恢复，操作前先备份
- 服务协议里另有一份不予退款的情形清单，包括遭受 DDoS 攻击、以网络状况不佳为由、IP 地理位置原因、同一产品系列退款已达 3 次等

也就是说，靠“3 天无理由”试机器是可行的，但别把它当成无限次免费试用，也别在被打或者以线路不好为由的情况下指望顺利退款。买之前先用测试 IP 自己 ping 一轮，比事后申请退款省事。
